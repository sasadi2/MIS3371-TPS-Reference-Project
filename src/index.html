Expense Reimbursement Request

Submit one eligible business expense for reimbursement. This page shows the complete transaction data model while clearly separating employee-entered data from system-controlled information.

Transaction Overview

The transaction begins when an employee prepares an expense request and ends when the request is either completed or rejected.

Reference business rules: Expenses greater than $75 require receipt evidence. Expenses greater than $5,000 require director approval.
