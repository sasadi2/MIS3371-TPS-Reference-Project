Expense Reimbursement Request

Submit one eligible business expense for reimbursement.

This reference page shows the complete transaction data model. Some values are entered by the employee, while others will later be created or controlled by the application.

Transaction Overview

The transaction begins when an employee prepares an expense request and ends when the request is either completed or rejected.

Expenses greater than $75 require receipt evidence. Expenses greater than $5,000 require director approval.

Employee-Entered Information

These fields represent business data entered directly by the employee.

Expense Request






Derived and Reference Information

These values belong to the transaction, but the employee should not manually control them. Later, the application will derive or look up these values.

Employee Name
Field: employeeName
Example: Jordan Lee
Source later: employee directory / application lookup
Department
Field: department
Example: Marketing
Source later: employee directory / application lookup
Manager ID
Field: managerId
Example: M2208
Source later: organizational directory / application lookup
Receipt Required
Field: receiptRequired
Example: true
Business rule: true when expense amount is greater than $75
Director Approval Required
Field: directorApprovalRequired
Example: false
Business rule: true when expense amount is greater than $5,000

System-Controlled Transaction Data

These values are part of the official transaction record. They should not be directly entered or changed by the employee.

Transaction ID
Field: transactionId
Example: EXP-2026-00418
Responsibility later: generated by application logic
Official Status
Field: status
Example: UnderReview
Responsibility later: controlled by valid application state transitions
